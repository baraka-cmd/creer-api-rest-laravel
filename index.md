# Bienvenue dans ce guide

Ce livre accompagne le lecteur dans la conception et la réalisation d'une API REST avec Laravel, depuis les fondamentaux du protocole HTTP jusqu'à la sécurisation, aux tests et à la préparation d'un déploiement.

Le fil conducteur est **ProxiServices**, une plateforme fictive de mise en relation entre clients et professionnels. Les exemples servent à illustrer les décisions de conception et les pratiques de développement. Ils doivent être adaptés et vérifiés dans le contexte de chaque application réelle.

## Comment utiliser ce livre

- Suivez les chapitres dans l'ordre pour construire progressivement les compétences.
- Exécutez les commandes et les exemples dans un environnement de développement, jamais directement en production.
- Vérifiez les versions de PHP, Laravel et des dépendances indiquées dans votre projet.
- Réalisez les exercices et les tests avant de passer à la suite.
- Consultez les annexes pour les rappels, checklists et ressources pratiques.

## À propos des exemples

Une API professionnelle ne se limite pas à produire des réponses JSON. Elle doit aussi définir un contrat clair, contrôler les accès côté serveur, valider les données, protéger les ressources et être testable.

Les extraits de code du livre sont pédagogiques. Avant toute publication de logiciel ou mise en production, vérifiez leur cohérence avec les fichiers du projet, les routes réellement déclarées et la documentation officielle de la version utilisée.
