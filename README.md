# Créer une API REST professionnelle avec Laravel

> De zéro à une API sécurisée, testée, documentée et prête pour une application mobile ou web.

## Manuscrit de l'e-book

Ce dépôt contient le manuscrit éditorial et les ressources du livre. Les chapitres sont rédigés en Markdown pour faciliter la révision, l'historique Git et la génération ultérieure du PDF/EPUB.

## Structure
- `manuscript/` : chapitres du livre
- `assets/diagrams/` : schémas originaux
- `exercises/` : exercices et corrigés
- `references/` : références documentaires

## Principes éditoriaux
- français accessible, rigoureux et pédagogique ;
- progression du concept vers la pratique ;
- exemples cohérents avec le projet fil conducteur ;
- sécurité et bonnes pratiques expliquées dans leur contexte ;
- références officielles vérifiées avant la publication ;
- version du manuscrit identifiée et relue avant export commercial.
