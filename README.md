# Créer une API REST professionnelle avec Laravel

> De zéro à une API sécurisée, testée, documentée et prête pour une application mobile ou web.

## Manuscrit de l'e-book

Ce dépôt contient la source éditoriale Markdown du livre. Elle est destinée à la relecture, à la correction technique et à la préparation ultérieure des éditions PDF et EPUB.

## Contenu présent

- `manuscript/` : chapitres 1 à 29 et cahier de conception du projet fil conducteur.
- `REVUE-EDITORIALE-ET-TECHNIQUE.md` : audit du manuscrit et plan de correction.

**À noter :** le cahier de conception `30-cahier-conception-projet-fil-conducteur.md` n'est pas le chapitre final de réalisation. Le chapitre 30 pédagogique, les annexes A–J et les ressources complémentaires restent à rédiger ou à produire.

## Principes éditoriaux

- français accessible et rigoureux ;
- progression du concept vers la pratique ;
- exemples cohérents avec le projet ProxiServices API ;
- sécurité, tests et bonnes pratiques expliqués dans leur contexte ;
- références officielles vérifiées ;
- relecture technique et visuelle avant publication.

## État de publication

Le dépôt est un **manuscrit de travail**, pas encore un ebook final prêt à la vente. La cohérence des exemples, les annexes, le code compagnon, les ressources et la mise en page PDF/EPUB doivent encore être finalisés.

Les conditions de distribution du livre et du code compagnon seront précisées avant publication.
